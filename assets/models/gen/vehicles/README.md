# Original prototype vehicle assets

`light_tank.glb` and `tank_factory.glb` are original procedural project assets generated by
`tools/build_tank_assets.py`. No third-party model files or textures are included. Models use
material colors and named parts; the tank's Turret node is reserved for later independent aiming.

Run the generator with Python and Pillow to regenerate the GLBs, source icons and atlas entries.
