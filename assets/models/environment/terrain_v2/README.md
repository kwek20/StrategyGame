# Original V2 scenery

`conifer_1.glb` and `conifer_2.glb` are original project assets generated by
`tools/generate_terrain_conifers.py`. They contain faceted geometry and opaque material colors,
with no external textures or third-party source material. Rebuild from the repository root:

```powershell
python tools/generate_terrain_conifers.py
```

The models use a ground-level origin and world-unit dimensions. V2 vegetation rules apply scale
variation, deterministic grouping and shared tree spacing. They are decorative, clear on building
placement, and add no resource inventory or navigation obstacles.
