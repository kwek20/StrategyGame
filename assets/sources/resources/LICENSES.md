# Resource variant source assets

The processed GLBs in the parent directory are derived from the following source assets.

- **Scrap Metal Pile (Wipe Day Survival Island)** — 3DAssets.dev, CC0 1.0.
  <https://3dassets.dev/assets/wipe-day-survival-island-scrap-pile-110d7f1b>
- **Salvage Pile (Wipe Day Survival Island)** — 3DAssets.dev, CC0 1.0.
  <https://3dassets.dev/assets/wipe-day-survival-island-salvage-pile-902fe466>
- **Rusted Oil Barrel (Wipe Day Survival Island)** — 3DAssets.dev, CC0 1.0.
  <https://3dassets.dev/assets/wipe-day-survival-island-rusted-oil-barrel-918c7b9f>
- **Glowing Crystal Cluster (Sunken City and Underwater Ruins)** — 3DAssets.dev, CC0
  1.0. <https://3dassets.dev/assets/sunken-city-and-underwater-ruins-glowing-crystal-clust-897febc9>
- **Drops** by plaggy — OpenGameArt, CC0 1.0. The liquid mesh is used in the oil-seep
  derivative. <https://opengameart.org/content/drops>

All downloaded sources are retained in this directory or in
`assets/source_archives/resources`. Rebuild the game-ready variants with
`tools/process_resource_variants.py` through Blender.
